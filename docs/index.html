ytmd.

A Telegram bot that turns YouTube Music links into MP3s — hosted entirely on GitHub, no server required.

How to use

  1. Open the bot in Telegram and press Start.
  2. Paste a link, e.g. https://music.youtube.com/watch?v=…
  3. Wait a moment — the bot replies with the track as an MP3 (192 kbps, tagged, with cover art).

Why replies take a few minutes

There is no always-on server. A GitHub Actions workflow wakes up every ~5 minutes, collects the links sent since the last run, downloads them with yt-dlp, and uploads the audio back to your chat.

Limits

  1. Max 50 MB per file (Telegram bot upload limit).
  2. Single tracks only — playlists are not expanded.
  3. Personal use: only download content you have the rights to.
Source & setup instructions: see the GitHub repository.
